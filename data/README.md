# 🗃️ Directorio de Datos Persistentes — VELVET AI

En este directorio se almacenan los archivos de estado y bases de datos locales:
* `velvet.sqlite`: Base de datos SQLite para perfiles de clientes VIP (Whales), fetiches y rankings históricos.
* `session_cache.json`: Cache de sesiones y última posición conocida de las modelos monitoreadas.
